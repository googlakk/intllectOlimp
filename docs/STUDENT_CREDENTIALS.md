# Учётные данные учеников

В разделе управления аккаунтами можно создать ученика без заданного логина или
вставить список имён класса (по одному на строку). Допускается `Имя;Логин`,
а также импорт CSV/TSV/TXT. Логины автоматически подбираются с проверкой коллизий.

Пароль можно сформировать автоматически (8 символов без спецсимволов и похожих
знаков) или задать вручную (6–128 символов без пробелов). Политика Supabase Auth
может отклонить слишком простой пароль: её настройки эта функция не меняет.
При следующем входе ученик обязан задать постоянный пароль по прежним правилам.

Сменить пароль можно одному ученику, выбранным ученикам или всем активным ученикам
класса. Учитель ограничен назначенными классами, администратор — своей организацией.
При смене логины сохраняются. Результат можно скопировать или скачать в CSV;
пароли не сохраняются в журнале событий. Частичные ошибки показываются отдельно,
данные успешно обработанных учеников остаются в результате. Запросы отправляются
последовательно небольшими группами, без автоматического повторения изменений.
