# Статистика ученика

`/dashboard/students/:studentId` доступна администратору и учителю в пределах его активных классов и назначенных предметов. «Подробнее» в обзоре открывает эту страницу; возврат восстанавливает поиск и прокрутку списка в текущей вкладке.

## Показатели

- Текущая программа — опубликованные неархивные уроки класса ученика. Архив, другие классы и снятые с публикации уроки с сохранёнными результатами показываются отдельно.
- Каждый урок считается один раз. Средний результат включает последние завершённые оценённые результаты; измеренный ноль учитывается, отсутствие измерения отображается как «Нет данных».
- Пока повторное прохождение идёт, предыдущий завершённый результат остаётся виден. История всех попыток не выводится.
- «Пройден» и «Цели освоены» — разные показатели. Требование практики берётся из сохранённого mastery_status, а не из порога среднего балла.
- Сохранённое время — таймер урока; оно не является измерением активного внимания.
- Общие навыки и журнал помощника выделены отдельно, не являются предметными оценками.

## Ответы и версии

`Progress.response_details` хранит последний отправленный ответ на каждое задание. Ключ — исходный индекс блока или `<block>_q<question>`. Значение содержит читаемый `value`, `outcome`, необязательные `questionIndex` и `variant`. Событие не зависит от ИИ-помощника и не меняет правила оценки.

Условия, правильные ответы и критерии разбора берутся только из закреплённого `lesson_version_id`. Если версия недоступна, показываются сохранённые ответы без подстановки условий из новой редакции. Для старых записей текст ответа может отсутствовать.

## Включение

Владелец должен применить `supabase/migrations/20261103132035_student_response_details.sql` **до запуска обновлённого backend**. Миграция добавляет JSONB-колонку с пустым значением по умолчанию; прежние снимки попыток менять не нужно. Автоматического ALTER при запуске нет.

Миграция не применялась к общей базе. Публикация требует отдельного разрешения.

## Проверка без реальных данных

- Backend: из `backend/` — `../.venv/bin/python -m pytest test_dashboard_service.py test_student_statistics.py test_response_details.py test_progress_service.py test_tutor_report.py -q`.
- Frontend: `pnpm run typecheck`, `pnpm run test:run`, `pnpm run check:architecture`, `pnpm --filter ./artifacts/intellect-learning-platform run build`.
- Browser: запустить только Vite, затем `node scripts/src/student-statistics-smoke.mjs`. Smoke разрешает только localhost, подменяет все API синтетическими данными и не требует backend. Проверяет навигацию/возврат, URL фильтров, разбор, ошибки, 390/320 px; снимки — `output/playwright/`.
