# Мини-игры внутри урока

Реализовано локально 29 сентября 2026. Семь блоков на 3–7 минут: пять для совместной работы в классе, два для самостоятельной практики.

## Что видит учитель

Живая мастерская: `/visual/mini-games`. В библиотеке есть ссылка на мастерскую и фильтр «Мини-игры · 5 + 2». Демонстрации используют вымышленные задания и настоящий рендерер блоков. Никакая генерация при просмотре не запускается.

| Блок | Игра | Визуальное решение | Учебная работа |
|---|---|---|---|
| BossRaid | Одолей босса | Орбитальная станция, авторский SVG-персонаж, щиты | Команды одновременно обсуждают вопрос; учитель отмечает объяснивших ответ |
| CodeVault | Секретный код | Мятный сейф, латунные детали, цифровые барабаны | Группа решает задания и собирает код |
| KnowledgeAuction | Аукцион утверждений | Зелёный аукционный зал, бумажный лот, золотые монеты | Команды ставят игровые монеты на утверждения и обосновывают истинность |
| WordRelay | Объясни иначе | Коралловая студия, карточка ведущего, звуковая волна | Объяснение терминов без запрещённых слов; понятие скрывается перед ответом класса |
| PuzzleAssembly | Собери целое | Бирюзовый чертёж, янтарные фрагменты | Группа восстанавливает соответствия или структуру процесса |
| ErrorHunt | Почини решение | Светлая лаборатория, нумерованные строки | Каждый ученик отличает верные строки от ошибочных и выбирает исправления |
| LearningPath | Мой маршрут | Зелёный горный ландшафт, извилистая тропа | Ученик выбирает обычное или более сложное задание на каждом из трёх этапов |

Общие элементы: короткие правила, продолжительность, явный старт таймера, пауза, повтор игры с подтверждением, итог и содержательный вывод. Управление — кнопками, без обязательного перетаскивания. Цвет дополняется текстом и состоянием элементов. Анимации учитывают `prefers-reduced-motion`.

Групповые игры рассчитаны на общий экран и ответы вслух. Это не синхронная игра с подключением телефонов. Счёт групп хранится только в текущем блоке и не засчитывается как личное освоение темы.

## Связь с учебником и КТП

Все семь блоков доступны в существующем процессе добавления компонента: цель урока → подтверждённый материал учебника → подготовка → предпросмотр → вставка в черновик. Вопросы, понятия, ошибки и вывод должны относиться к выбранной цели; демонстрационные задания не копируются в реальный урок.

Подготовка содержимого использует платную модель, поэтому при разработке её не запускали. Структурные проверки требуют корректные задания, ответы, ссылку на источник и одну цель. Они не заменяют смысловую проверку учителем.

В генератор целого урока включены только два индивидуальных блока как необязательная практика: не более одной мини-игры в уроке, только при наличии материала учебника и подходящего шага плана. Пять групповых блоков добавляются учителем через библиотеку. Так общеклассная игра не назначается как самостоятельное задание ученику.

## Где находится реализация

- `artifacts/intellect-learning-platform/src/features/miniGames/`: семь компонентов, общая оболочка, стили, типы, проверки данных и демо.
- `components/blocks/BlockRenderer.tsx`: отложенная загрузка игровых экранов.
- `features/componentCatalog/`, `features/lessonEditor/`, `lib/lessonBlocks.ts`: библиотека, вставка и классификация ответов.
- `backend/component_registry.json`: C48–C54.
- `backend/services/mini_games.py`: детерминированные проверки контрактов.
- `backend/ai/component_generator.py`, `planner.py`, `generator.py`, `backend/objectives.py`: подготовка по источнику, планирование и ограничения размещения.

Миграций и новых зависимостей нет. Бэкенд нужно перезапустить вручную.

## Дизайн: использованные принципы

- [Xbox Accessibility Guidelines: contrast](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/102): читаемость элементов и состояний — особенно важна на экране перед классом.
- [Atlassian: applying motion](https://atlassian.design/foundations/motion/applying-motion): движение помогает увидеть реакцию интерфейса; предусмотрено уменьшение движения.
- [Duolingo: imagery](https://design.duolingo.com/identity/imagery): выразительная простая графика. Иллюстрации здесь собственные, созданы средствами SVG/CSS.

## Что проверено

После добавления мини-игр прошли `pnpm run typecheck`, сборка фронтенда, `pnpm run check:architecture`, синтаксический разбор изменённых Python-модулей, `git diff --check`. Выполнен краткий визуальный просмотр локальной мастерской.

Полный `pytest`, frontend tests и `pnpm run check:quality` после этих изменений не запускались. Числа тестов из предыдущего дополнения handoff относятся к состоянию до семи мини-игр. Сквозная подготовка платной моделью, вставка в реальный урок и все игровые сценарии в браузере не проверены. Перед коммитом нужен полный согласованный набор проверок.

На прод не выкладывалось; реальные данные не изменялись. Изменения оставлены в рабочей копии без коммита.
